# Archivos de configuración

Esta carpeta conserva las configuraciones y evidencias de texto del proyecto. La memoria de `docs/` explica el procedimiento, las decisiones y las pruebas.

| Componente | Archivos y procedencia | Explicación y pruebas |
| --- | --- | --- |
| Router R-N02 | [Inventario](router/README.md) | [Router](../docs/router.md) |
| DNS y DHCP | [Inventario](dns-dhcp/README.md) | [DNS y DHCP](<../docs/DNS y DHCP.md>) |
| Clientes | [Inventario y reutilización del Netplan](clientes/README.md) | [Clientes](../docs/Clientes.md) |
| FTP F-N02 | [Netplan y fragmento de vsftpd](ftp/README.md) | [Servidor FTP](<../docs/Servidor FTP.md>) |
| Web W-N02 | [Netplan y fragmento PHP](web/README.md) | [Web y aplicación](<../docs/Servidor web, SSH y aplicación de prueba.md>) |
| Base de datos | [Historial original y archivos pendientes](bbdd/README.md) | [Base de datos](<../docs/Base de datos.md>) |

Cada inventario distingue entre transcripciones de capturas, contenido trasladado de una memoria, fragmentos y propuestas. Ninguno equivale automáticamente a una exportación completa y verificada de la VM actual. Los fragmentos de configuración y los historiales no deben instalarse como si fueran archivos completos del sistema.
